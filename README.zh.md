# dsh-webview-remote

**安全地用手机 App 连上你电脑里的 DSH。**

*[English version](README.md)*

App 由 **WebView** 驱动 —— **DSH 的页面长什么样，App 里就是什么样**，
第三方插件的 UI 也能正常显示。

两半：

| | |
|---|---|
| [`Server/`](Server/) | **DSH 插件** —— 带鉴权的反向代理，外加设置页里的一栏配置界面 |
| [`Client/`](Client/) | **Flutter App**（安卓 + 鸿蒙）—— 一个 WebView 外壳 |

## 怎么连的

```
手机 ──(一道密码)──▶ Server：监听 0.0.0.0:<端口>
                       │  附上 DSH 自己的启动 token
                       ▼
                    DSH：127.0.0.1
```

## 快速开始

1. **装插件** —— 在 DSH 插件面板里安装 `@nszzj/dsh-webview-remote-server`
2. **设置 →「WebView 远程」** —— 设访问密码和监听端口，保存。
   状态行应该变成「**正在监听 0.0.0.0:<端口>**」
3. **装 App** —— 下载 [Release](../../releases/latest) 中的 app，在里面填同样的地址和密码。
   （手机浏览器**进不去**：密码走请求头，而且**没有登录页**。）

## ⚠️ 安全 —— 开之前请读完

| | |
|---|---|
| **密码就是唯一的边界** | 拿到它的人，就能在那台机器上**执行命令** —— 因为 DSH 的能力就是这个。 |
| **默认零暴露** | 没设密码时，插件**一个端口都不监听**（不是"监听了但拒绝"，是压根不 `listen`）。 |
| **明文 HTTP** | 局域网里能嗅探到密码和全部流量。**别在不可信的网络上开**（咖啡厅 / 酒店 / 访客网）。 |
| **绝对不要映射到公网** | 端口转发、frp、ngrok 之类的都不要接。 |
| **没有管理面** | 远程客户端看不到 DSH 的模型设置页，也改不了本插件的配置。 |
